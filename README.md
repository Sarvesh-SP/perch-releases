# Perch releases

Download page, privacy policy, DMGs and the Sparkle update feed for Perch,
deployed on Netlify (static, no build step; see `netlify.toml`).

Files here are produced by `scripts/release.sh` in the (private) app repo:
`downloads/Perch-<version>.dmg`, `Perch.dmg` (latest), `appcast.xml`.
